
Use this prompt to recreate the current application:
Build a complete, working native desktop application named “ChaosBox Desktop” for Ubuntu 24.04.

The application manages images, videos, and inventory records using file-based storage. Implement the application, installation scripts, documentation, and tests—not just a mockup or implementation plan.

1. Technology and architecture

Use Python 3, Tkinter/ttk, Pillow, GExiv2 (Python GI binding), Mutagen, markdown-it-py, FFmpeg/FFprobe, and Paramiko.

Separate the GUI from storage and metadata operations:
- app.py: windows, dialogs, thumbnail selection, editing, and previews.
- core.py: configuration, metadata, file operations, indexing, search, and upload.
- setup.ini: default profiles and settings.
- tests/: automated tests and a graphical smoke test.

Use background workers for expensive operations. All Tk operations must run on the main thread. Keep the interface responsive and cancel pending callbacks safely when windows close.

Support English, German, French, and Italian UI translations selected through `Language=en|de|fr|it` in the global `[App]` section of setup.ini. Preserve the configured language of custom labels, categories, and text snippets.

2. Profiles and configuration

Support multiple profiles configured through setup.ini.

Provide these defaults:
- The installation itself has no media folders and is not a selectable profile.
- Child projects: <installdir>/<Titel>/JPG and <installdir>/<Titel>/TXT.

Default --installdir to ~/ChaosBox. Store setup.ini, .indices and .state inside it.

Support:
- [App] configures inherited defaults; only Box sections are selectable, starting with the first.
- Repeated [Box] sections with Titel, Felder and Kategorie; Titel determines the child folder.
- [ImageSize] with LIMIT=3000.
- [TextSnippets] with named, multiline text snippets.
- [SSH] with connection settings and local credential paths.

Box titles determine subfolders beneath the installation directory. Empty custom field labels hide those fields.

Provide a Setup editor. Remember the selected profile and the last selected media folder separately for each profile across application restarts.

Support --installdir, --newindex, --state-dir, --setup and --check command-line options.

3. Main editor

Provide:
- Profile selector.
- Open JPG / MP4.
- Open JSON.
- Save.
- Clear.
- Search, Cancel search, and Repeat search.
- TXT.
- Setup.
- Upload saved files.
- Image preview, status messages, and progress indication.

Use these metadata keys:
box, anzahl, device, alias, category, comment, package, created.

Display the default labels:
Box, Quantity, Device, Alias, Category, Comment, Package.

Provide Markdown source and rendered Preview tabs for Comment, preserving the exact source on save. Render headings, bold/italic, strikethrough, lists, quotes, links and code consistently in the preview and poster captions. Account for styled text dimensions when fitting poster captions.

Use a multiline Comment editor and an editable Category selector. Quantity must be a nonnegative integer. Omit modified from JSON records. For media, created uses the capture timestamp from EXIF, then the filename, then an existing created value, finally the original file modification time as an approximation. Preserve creation timestamps for non-media records.

Support Ctrl+O, Ctrl+S, and Ctrl+F.

4. Media selection

“Open JPG / MP4” opens a resizable window that supports maximizing and restoring through the title bar.
All visible labels, captions, and controls in this media-selection window must be in German.

Show only media files directly inside the current folder. Do not recursively include files from subfolders.

Start in the last selected folder for the active profile. Fall back to the profile’s media folder if that folder is unavailable.

Provide:
- A scrollable thumbnail grid.
- A column selector from 1 to 10.
- Click to toggle individual selections.
- Shift-click for range selection.
- “Alle auswählen”, “Auswahl aufheben”, “Abbrechen”, “Selektion editieren”, and
  “Einzelbilder editieren”. “Selektion editieren” preserves the existing
  multi-selection editing behavior.
- “Ordner wählen …”.
- “Andere Dateien …” for importing JPG, JPEG, PNG, and MP4.
- “Metadaten anzeigen” beside the column selector.

“Einzelbilder editieren” opens the selected files one at a time, starting with
the first selected file. Saving keeps the current image displayed. A “Felder
leeren” action clears its editable metadata fields without closing the image.
The preview arrows cycle through only the selected files in this mode.

Keep selections when changing the number of columns. Resize thumbnails proportionally to their available width. Load visible previews in the background with bounded image caching. Damaged previews must not prevent file selection.

In the folder picker:
- A double-click selects the clicked folder, closes the picker, and opens that folder’s images immediately.
- Provide an Up button and an editable path field.
- Pressing Enter in the path field navigates to that directory.
- Do not include Go or Browse buttons.

5. Show metadata

Place a checkbox labeled “Metadaten anzeigen” beside the column selector.

When enabled, display the parsed metadata values below each thumbnail in this exact order:

box | category | comment

Display the entire combined caption, including the complete comment in its original Markdown source form. Preserve line breaks and whitespace; do not render Markdown or truncate. Keep empty field positions; show no caption when all three fields are empty.

Read metadata asynchronously. Do not change the stored metadata when formatting captions. Adjust tile heights so full captions remain visible at different column counts.

6. Saving media

Use the first selected file to populate the editor. Saving applies the form values to all selected files.

Save media inside the active profile’s media root:
- With a category: use the category folder.
- Without a category: use unassigned.

For category-folder naming, use the first category, trim whitespace, convert to lowercase, and sanitize path separators and control characters. Reject unsafe destination paths.

Move existing profile media into the appropriate folder when its category changes. Update media already in the correct folder in place.

For external imports, preserve the source and create a separate file with an _cb suffix. Resolve filename collisions using numbered suffixes without overwriting unrelated files.

Convert PNG to JPEG with a white background. Resize images only when they exceed the configured limit. Preserve the encoded image data of smaller JPEGs and do not re-encode MP4 audio or video.

Store image metadata as individual embedded XMP properties using the GExiv2 Python binding:
- Comment in dc:description (x-default), created in xmp:CreateDate.
- box, anzahl, device, alias, category and package in the ChaosBox namespace urn:chaosbox:metadata:1.0/.
- chaosbox:version=1 marks a complete record, including cleared fields.
Read legacy EXIF UserComment records and migrate them on save, removing UserComment and its XMP EXIF mirror only from the successfully saved output. Preserve other image metadata.
Store MP4 metadata as JSON in ItemList Comment using Mutagen, synchronizing existing Keys Comment metadata. Use FFprobe for capture dates and legacy comment fallback. Do not depend on ExifTool.

Write to a temporary file, verify the metadata, and install the result atomically. Remove a moved source only after successful verification and installation. Preserve recoverable state after partial batch failures.

7. JSON records and search

Support creating and editing JSON inventory records. Allow selecting individual records through Device or a separate record chooser when that field is hidden.

Preserve unknown JSON fields and creation timestamps. Read legacy aliases such as count, pack, and kommentar.

Maintain a separate search index per profile. After saving, update only affected entries, including removal of old paths for moved files. Rebuild the index at startup, before searches, or when the cache is missing or invalid.

Use case-insensitive regular-expression search:
- Combine nonempty query fields with AND.
- Category and Device also search Comment.
- Comment and Alias search Device, Alias, and Comment.

Cancel search restores the previous editor state. Repeat search reruns the last query.

8. Preview and clipboard

Overlay transparent previous/next double-chevron buttons at the left and right edges of the preview. Browse the selected images when images are selected; browse neighboring JSON files otherwise. Navigation wraps from the last item to the first and from the first item to the last.
Keep the arrows visible on empty JSON previews with a bright contrasting color. When a JSON record is open, clicking the center of the preview lets the user choose image/video media; preserve the record fields and save them into media in the profile's JPG folder.
Double-click the main preview to open the selected file with the system's default application.
Right-click the image to display its percent-encoded file:// link and offer copying that link.
Also offer "Open in editor", launching the editor configured by `editor=` in setup.ini with the selected file path.
Do not show a separate full-screen image viewer or a Copy path button.

Show a still preview for MP4 files; an embedded video player is unnecessary.

TXT displays configured snippets and copies the selected snippet to the clipboard.

9. Manual upload

Upload must run only when explicitly requested.

Use SFTP with public-key authentication and known-host verification. Keep credentials outside source packages.

Upload only eligible profile data beneath the selected installation directory. Preserve relative subdirectories. Send files that are missing remotely or newer locally, using temporary remote files and atomic rename.

Do not delete remote extra files. Support cancellation and report failures without deleting local data.

10. Delivery and verification

Provide:
- Launch and dependency-check scripts.
- A per-user installer with an application-menu entry.
- An architecture-independent Debian package builder.
- Application icons.
- A README covering installation, configuration, operation, and testing.

Installation and upgrades must preserve user data and configuration. Never package private keys.

Test metadata round-trips, caption formatting and the 60-character limit, folder persistence, nonrecursive selection, double-click folder acceptance, category moves, collision handling, failed-save recovery, JSON preservation, indexing, search, and simulated SFTP.

Include a Tk smoke test for GUI workflows. Use temporary test data and never contact a live server during tests.

Implement the complete application, run the available checks, and report the resulting files, launch commands, test results, and any verification limitations.

Window and desktop app title: Chaosbox-<installation directory name>.
install-desktop.sh --installdir creates a separate app and launcher bound to that full path.
